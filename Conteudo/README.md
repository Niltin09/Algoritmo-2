# Conteudo - Algoritmo 2

Material do semestre organizado para consulta e publicacao no GitHub.

## Estrutura

- `Conteudo/Exercicios/`
- `Conteudo/Materiais/`
- `Conteudo/Provas/`
- `Conteudo/Trabalhos/`

## Navegacao

- indice geral: `Conteudo/INDICE.md`
- resumo para prova: `Conteudo/Provas/P1_RESUMO.md`
- regras de escopo: `Conteudo/Exercicios/REGRAS_CONTEUDO.md`

## Padrao do repositorio

- nomes em `snake_case`
- sem binarios ou pastas de `output`
- foco em codigo-fonte, materiais e resumos
