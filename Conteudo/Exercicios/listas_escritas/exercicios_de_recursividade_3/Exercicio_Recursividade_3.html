Exercício de Recursividade 3

1) Pré-ordem (n = 4)

func(int n){
  if (n == 0) printf("fim");
  else { printf(n); func(n-1); }
}

Saída: 4 3 2 1 fim

func(4)
  print 4
  func(3)
    print 3
    func(2)
      print 2
      func(1)
        print 1
        func(0)
          print fim

2) Pós-ordem (n = 4)

func(int n){
  if (n == 0) printf("fim");
  else { func(n-1); printf(n); }
}

Saída: fim 1 2 3 4

func(4)
  func(3)
    func(2)
      func(1)
        func(0)
          print fim
        print 1
      print 2
    print 3
  print 4

3) Pré e pós (n = 4)

func(int n){
  if (n == 0) printf("fim");
  else {
    printf(n);
    func(n-1);
    printf(n);
  }
}

Saída: 4 3 2 1 fim 1 2 3 4

... func(0) -> fim
na subida: 1, 2, 3, 4

4) Infixa com duas chamadas (n = 3)

func(int n){
  if (n == 0) printf("fim");
  else {
    func(n-1);
    printf(n);
    func(n-1);
  }
}

Saída: fim 1 fim 2 fim 1 fim 3 fim 1 fim 2 fim 1 fim

func(3)
  func(2) -> fim 1 fim 2 fim 1 fim
  print 3
  func(2) -> fim 1 fim 2 fim 1 fim

6) Pós-ordem com duas chamadas (n = 3)

func(int n){
  if (n == 0) printf("fim");
  else {
    func(n-1);
    func(n-1);
    printf(n);
  }
}

Saída: fim fim 1 fim fim 1 2 fim fim 1 fim fim 1 2 3

7) Euclides (fazAlgo)

int fazAlgo(int x, int y){
  if (y == 0) return x;
  else return fazAlgo(y, x % y);
}

Entradas e resultados:

  • 12 e 18 → 6 (trajeto: (12,18) → (18,12) → (12,6) → (6,0))
  • 6 e 9 → 3 (trajeto: (6,9) → (9,6) → (6,3) → (3,0))

O que calcula? O MDC (máximo divisor comum) pelo algoritmo de Euclides.
