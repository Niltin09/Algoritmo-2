# Lista - Vetores e Ponteiros

Lista focada em percorrer vetores com aritmetica de ponteiros e em inverter ou comparar valores dentro do arranjo.

## Conteudos principais

- maior e menor valor em vetor
- troca de elementos
- leitura invertida
- inversao de vetor
