# Lista - Passagem por Referencia

Lista dedicada a funcoes que alteram valores por meio de ponteiros.

## Conteudos principais

- escrita em parametros de saida
- comparacoes com retorno por referencia
- funcoes do tipo `void func(..., tipo *out)`
