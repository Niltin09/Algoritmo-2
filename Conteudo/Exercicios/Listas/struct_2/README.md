# Lista - Structs 2

Lista centrada em structs de DVD e Pokemon, comparando diferentes formas de leitura, retorno e alocacao.

## Conteudos principais

- `struct` local
- `struct` retornada por funcao
- preenchimento via ponteiro
- alocacao dinamica com `malloc`

## Arquivos

- `Exercicio_01.c` a `Exercicio_08.c`
- variantes `_07` e `_08` para comparar abordagens
